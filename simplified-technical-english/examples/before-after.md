# Before / After — Worked Examples

Each example shows the original sentence, the rule it violated, and the STE-style rewrite.

## Example 1 — Tool description

**Original:**

> This tool will attempt to synchronize state across the various backends that have been configured, and if a conflict is detected it may resolve it automatically depending on the strategy that has been set, or otherwise it will surface the conflict for manual review.

**Violations:** present perfect ("have been configured," "has been set"), passive voice ("a conflict is detected"), multi-instruction sentence, noun cluster, ambiguous verbs ("attempt," "resolve," "surface").

**Rewrite:**

> The tool synchronizes state across the configured backends. If the tool finds a conflict, it checks the current strategy. If the strategy allows automatic resolution, the tool resolves the conflict. If not, the tool reports the conflict for manual review.

## Example 2 — Error message

**Original:**

> An error may have occurred while processing your request due to a possible mismatch in the expected data format, which could be caused by an outdated client version.

**Violations:** present perfect ("may have occurred"), ambiguous hedge ("may," "possible," "could be"), noun cluster ("expected data format"), passive voice with unknown actor.

**Rewrite:**

> The request failed. The data format did not match what the server expected. Check your client version — an outdated client is the most common cause.

## Example 3 — Status report (agent to agent)

**Original:**

> I have successfully completed the migration of all the user records that were flagged as requiring attention into the new database schema, however there are a few items that will need to be looked at by someone with elevated permissions before the process can be considered to be fully finished.

**Violations:** present perfect ("have successfully completed," "were flagged," "will need to be looked at"), passive voice ("were flagged," "be looked at"), noun cluster ("user records ... database schema"), multi-instruction sentence, wordy hedge ("a few items," "elevated permissions," "considered to be fully finished").

**Rewrite:**

> I moved the flagged user records into the new schema. The migration is done. Three items remain and need an admin to approve them before I can close the task.

## Example 4 — Inter-agent instruction

**Original:**

> When you have finished analyzing the dataset that has been provided to you by the user, please make sure to save the output that has been generated by your analysis to the location that was specified in the original request so that the next agent in the pipeline can pick up where you left off.

**Violations:** present perfect ("have finished," "has been provided," "has been generated," "was specified"), passive voice, multi-instruction sentence, noun cluster ("dataset," "output," "location," "next agent," "pipeline").

**Rewrite:**

> When you finish the analysis, save the output to the path the user gave. The next agent reads from that path.

## Example 5 — Compound sentence with dropped subject

**Original:**

> Files not backed up will be lost.

**Violations:** ellipsis (the dropped subject "that are" before "not backed up" makes the sentence ambiguous — files that have not been backed up, or files that exist and will not be backed up if something happens?).

**Rewrite:**

> The system deletes files that you did not back up.

## Example 6 — Noun cluster

**Original:**

> The agent task queue priority handler assigns a numeric priority value.

**Violations:** noun cluster ("agent task queue priority handler" — 5 nouns stacked).

**Rewrite:**

> The handler sets a numeric priority for each item in the agent task queue.

## Example 7 — Safety instruction

**Original:**

> Please be aware that the high pressure fuel pump inlet valve assembly should not be removed while the engine is running, as serious injury could result.

**Violations:** safety warning buried mid-sentence, hedge ("could result"), noun cluster ("high pressure fuel pump inlet valve assembly"), passive voice ("is running").

**Rewrite (STE Section 7 — safety instructions):**

> WARNING: Risk of serious injury. Do not remove the fuel pump inlet valve while the engine runs.

## Example 8 — Already compliant

**Original:**

> The agent reads the file, parses the JSON, and writes the result to stdout.

**Verdict:** STE-compliant. Active voice, simple present, three short sentences joined by a list. No rewrite needed.

**Note:** do not force changes onto text that already complies.
